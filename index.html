Transforme ton projet web en projet d’installation Windows

Configure ton application, importe son dossier et génère un ZIP contenant les fichiers du projet, le lanceur Chrome, le script Inno Setup et les instructions. Les fichiers sont traités localement dans ton navigateur.

01 · IMPORTERChoisis le dossier de ton application web.
02 · CONFIGURERDéfinis le nom, la version, l’icône et les raccourcis.
03 · EXPORTERTélécharge le projet ZIP prêt à compiler.

① Identité de l’application

Utilisé pour le nom du dossier et du fichier d’installation.
Le fichier doit se trouver dans le dossier web importé. Les sous-dossiers sont conservés.
Choisis une image depuis ton ordinateur (PNG, JPG/JPEG, GIF, BMP, WebP, SVG et autres formats que le navigateur sait lire). Elle sera convertie en fichier .ICO pour Inno Setup. Les formats non décodables par le navigateur ne peuvent pas être convertis.
Aucune icône sélectionnée : l’icône par défaut sera utilisée.

② Importer les fichiers du projet

Choisir le dossier complet du site

Sur Chrome : sélectionne le dossier qui contient index.html, CSS, JS, images et autres ressources.

Ou sélectionner plusieurs fichiers

Pour un projet multi-fichiers, préfère la sélection du dossier afin de préserver l’arborescence.

Aucun fichier sélectionné pour le moment.

Le navigateur choisi doit être présent sur le PC cible. Ce paquet ne contient pas Chrome, Edge, ni un moteur Chromium.

Sélectionne les fichiers de ton projet pour lancer les vérifications.
